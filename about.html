About This Game

// Origins

How It All Started

Endless Zombie Shooter was born out of a simple idea: what if a zombie shooter could be played instantly in any browser, with no downloads, no accounts, and no barriers — just pure survival gameplay?

"I wanted to build something that you could share with a friend, they click the link, and they're playing within seconds. No installs. No accounts. Just a game."

— Indie Developer

What started as a weekend experiment in HTML5 canvas and JavaScript grew into a fully fledged game with multiple weapons, enemy types, and wave mechanics. Every element — from enemy pathfinding to weapon feel — was built and refined from scratch.

The project is hosted on GitHub Pages, making it freely accessible to anyone in the world with a browser and an internet connection.

// The Developer

Made by One Person

Endless Zombie Shooter is an independent project — designed, developed, and maintained by a single developer under the name Indie Developer. There's no studio, no team, no budget. Just a passion for games and a drive to build things.

As an indie developer, every decision in this game — from game mechanics to UI design — is made with the player experience in mind. Feedback from the community shapes every update.

The game is completely free to play, and will always remain free. It's built for fun, not profit.

// Tech Stack

Built With

The game is built using open web technologies — no game engines, no heavy frameworks. Just clean, hand-written code.

🌐
HTML5 Canvas
All rendering is done via the Canvas 2D API for maximum performance
⚙️
Vanilla JavaScript
Game logic, physics, and AI written in pure JS — no engines
🎨
CSS3
UI elements, menus, and HUD styled with modern CSS
🚀
GitHub Pages
Hosted for free with fast global CDN delivery
// Development Timeline

The Journey

v0.1

First Prototype

Basic movement, a single weapon, and simple zombie AI. The core loop was established — survive wave after wave.

v0.3

Weapon System

Added multiple weapon types with distinct stats. Shotgun, pistol, and rifle each feel and play differently.

v0.5

Enemy Variety

Introduced different zombie types: walkers, runners, and heavy armored zombies that require different tactics.

v1.0

Public Launch

First public release on GitHub Pages. Full wave system, scoring, drops, and polished UI. The game you can play today.

Ongoing

Continued Updates

Bug fixes, balance tweaks, new enemies, and features are regularly added. Check the blog for the latest updates.

// Philosophy

Design Values

⚡
Instant Access
No barriers between a player and the game. Click and play — always.
🎮
Gameplay First
Every feature serves the gameplay loop. If it doesn't make the game more fun, it doesn't ship.
🆓
Always Free
No paywalls, no pay-to-win mechanics. The full game is free for everyone, forever.
🔁
Replayability
Every run should feel different. Randomised drops and scaling difficulty ensure no two sessions are the same.
